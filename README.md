# AdGenius: AI Ads Copy & Text

An automated AI-powered marketing assistant built specifically for Shopify merchants to generate high-converting sales copies for Facebook, Instagram, and TikTok ads.

## 🚀 Tech Stack
- **Framework:** Remix (Node.js) & React
- **Database ORM:** Prisma with PostgreSQL (Deployed on Render)
- **UI Components:** Shopify Polaris & App Bridge
- **Billing:** Shopify Billing API integrated

## 🛠️ Environment Variables Required
- `DATABASE_URL`: PostgreSQL connection string.
- `SHOPIFY_API_KEY`: Application Client ID from Shopify Partners.
- `SHOPIFY_API_SECRET`: Application Client Secret from Shopify Partners.
- `SHOPIFY_APP_URL`: Production URL (e.g., https://onrender.com).
